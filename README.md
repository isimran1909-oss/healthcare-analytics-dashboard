# Healthcare Analytics and Patient Insights Dashboard

## Project Overview

This project demonstrates an end-to-end healthcare analytics workflow using Python and Power BI.

The dataset contains patient demographics, diagnosis information, billing details, blood pressure measurements, treatment outcomes, and hospital-related information.

## Objectives

- Clean and preprocess healthcare data
- Analyze patient demographics
- Explore disease prevalence
- Study billing and revenue patterns
- Evaluate doctor and department performance
- Visualize healthcare insights through an interactive Power BI dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Power BI
- DAX

## Data Cleaning Tasks

- Missing value treatment
- Duplicate handling
- Categorical value standardization
- Blood pressure feature engineering
- Data type corrections

## Dashboard Features

- Total Patients
- Total Revenue
- Average Billing Amount
- Age Group Analysis
- Gender Distribution
- Disease Analysis
- Revenue by Diagnosis
- Revenue by Department
- Doctor Performance
- Patient Outcome Analysis
- Monthly Admission Trends

## Key Insights

- Identified the most common diagnoses
- Compared department-wise revenue
- Analyzed patient demographics
- Examined healthcare outcomes and billing patterns
